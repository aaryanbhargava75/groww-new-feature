# groww-new-feature - BuroGTT Pro Prototype

BuroGTT Pro helps investors spend less time checking stocks manually. Save a watchlist and screening rules, then review which stocks match as data updates. The prototype also lets you explore stock metrics, set fundamental GTT alerts, and hand off to Groww or Zerodha. It is a screening prototype, not investment advice or an automated trading service.

## Deploy on Netlify

Netlify publish directory: . (no build step required). Pre-configured with 
etlify.toml.

## Notes

- This is a clickable prototype, not a production trading service.
- Broker buttons hand off to Groww or Zerodha; the prototype does not place orders or handle OTP/payment credentials.
- Quote display code uses a third-party public proxy. Availability and data accuracy depend on that external service.
